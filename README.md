# ICICI Bank Model Assessment Practice Website

An independent, static practice website containing 200 model questions in English across seven sections.

## Files
- `index.html` — welcome screen, candidate form, exam interface, and results page
- `style.css` — responsive styling
- `script.js` — bundled question bank, timer, navigation, scoring, answer review

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the Pages deployment and open the URL shown by GitHub.

## Important
This is an independent educational practice resource, not an official ICICI Bank website and not affiliated with or endorsed by ICICI Bank. Questions are model practice questions, not actual exam questions. The candidate name and email are handled in the browser only; no backend or server-side storage is configured.

## Question bank note
The four options are assembled from answers within the same section to make the practice interface interactive. Some distractors may be unrelated to a particular question; review the correct answer and explanation after submitting.
